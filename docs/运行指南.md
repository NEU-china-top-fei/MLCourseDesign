# 运行指南

## 环境与数据
四项任务的模型训练主要使用 Kaggle GPU。按任务选择竞赛数据：2026task1、2026task2、2026task3 和 2026task-4。

| 任务 | 环境准备 | 启动方式 |
| --- | --- | --- |
| 植物分类 | 挂载竞赛原图，启用 GPU 与网络 | 导入任务一 V2 Notebook，顺序执行全部单元 |
| 表情识别 | 挂载竞赛数据及配置列出的父输出 | 按任务二 README 中的阶段顺序运行 |
| 中央凹定位 | 挂载竞赛数据与 V25 父输出 | 按固定父清单运行 V26 完整 Notebook |
| 血管分割 | 挂载竞赛数据，迁移成员按配置挂载模型附件 | 运行任务四所列训练 Notebook |

各实验的 kernel-metadata.json 记录数据、模型附件与父任务输出。移入个人 Kaggle 账号时，按需修改账号和附件地址。

## 依赖和输出
Notebook 中保留训练依赖与参数。云端训练通常将提交文件、模型权重、预测概率、指标和训练历史写入 /kaggle/working/，完整权重和概率数组可从相应 Kaggle 输出下载。
