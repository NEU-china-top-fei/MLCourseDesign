# 任务三 眼底中央凹定位

训练集 80 张眼底图像，测试集 20 张，每张图像预测原图坐标系中的 X、Y 坐标。最终 V26 方案正式公榜 RMSE 为 11.49742。

## 训练主线

| 组件 | 入口 | 作用 |
| --- | --- | --- |
| V25 父模型 | [完整 Notebook](kaggle_v25/train.ipynb) | 两阶段定位基线，为 V26 提供父模型输出 |
| V26 主方案 | [完整 Notebook](kaggle_v26/train.ipynb) | 双粗定位、共享 ROI 与细模型融合 |
| 基础组件 | [引擎与配置](reference/README.md) | 热图回归、交叉拟合裁剪、校准与回退 |

粗、细模型采用 ResNet18 编码器、跳跃连接解码器与 64×64 热图。V26 融合两组粗定位的坐标和协方差，按预测不确定性构造共享 ROI。两组细模型在同一裁剪上推理，结果平均后进行校准。

新增种子完整训练流水线，并采用五折外层评价。V26 主方案外层 OOF RMSE 为 26.86854，ROI 覆盖率为 100%。模型细节见 [V18 对照](analysis/v18_design.md)与[V26 设计](analysis/v26_design.md)。
