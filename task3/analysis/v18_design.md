# V18 ResNet18 与 FPN 模型家族

训练集包含 80 张眼底图像，采用固定种子的五折交叉验证，每折 64 张训练、16 张验证。模型共七个成员：五个 RGB 模型，以及两个增加视盘高斯通道的四通道模型。

各成员使用 ImageNet 初始化的 ResNet18 编码器和宽度为 96 的 FPN 解码器。编码器 stem、layer1 参数及 BatchNorm 统计量保持冻结。输入尺寸为 512×512，训练 60 轮，batch size 为 8；优化器为 AdamW，编码器学习率 2e-4，解码器学习率 1e-3，weight decay 为 1e-4，采用三轮预热和余弦退火。

训练目标为 sigma 1.2 的高斯热图，使用归一化交叉熵和 0.01 倍坐标 L1 损失。数据增强包括旋转、缩放、平移、水平翻转和颜色扰动。每五轮在验证折评估并选择 RMSE 最低的检查点。

推理时以热图峰值周围的 13×13 区域进行概率平方加权解码。单模型先融合 512 与 384 两种输入尺度，再对七个成员的坐标取中位数。
